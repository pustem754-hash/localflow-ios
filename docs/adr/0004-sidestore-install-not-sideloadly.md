# Установка через SideStore, а не через Sideloadly

## Контекст
Изначально план предполагал путь через Sideloadly с бесплатным Apple ID: ноутбук с Windows нужен каждые 7 дней в той же Wi-Fi сети, чтобы продлить подпись приложения. Позже появилось отдельное условие: поставить приложение один раз и дальше не продлевать подпись руками, не платя 99 $ в год, на установленной версии iOS 26.6.1.

## Решение
Основной путь установки — SideStore вместе с инструментом iloader: компьютер нужен только один раз, при самой установке; дальше подпись продлевается в фоне или нажатием кнопки на самом телефоне (при включённом сопутствующем VPN-приложении для продления). Sideloadly остаётся запасным путём, описанным отдельным разделом в инструкции по установке.

## Почему
- Рассмотрели и отвергли TrollStore (установка один раз навсегда, без переподписи): по README проекта на GitHub поддерживаемые версии — «14.0 beta 2 – 16.6.1, 16.7 RC (20H18), 17.0», а «17.0.1+ will NEVER be supported» — на iOS 26.6.1 такая установка невозможна.
- Рассмотрели Sideloadly как основной путь и отклонили именно для условия «один раз и навсегда»: по его собственному описанию подпись действует 7 дней, продление требует ноутбук в одной сети с телефоном — это и есть то действие, от которого хотели избавиться.
- SideStore подошёл по официальной документации проекта (docs.sidestore.io): «You only need a computer once during installation» — компьютер нужен только при установке, дальше продление идёт с самого телефона.

## Последствия
Гарантии «навсегда без единого действия» нет: подпись всё равно истекает раз в 7 дней, условия фонового продления SideStore в документации не расписаны подробно, для продления нужен включённый VPN для продления. Файл сопряжения с компьютером может слететь при обновлении или сбросе iPhone — тогда компьютер нужен снова. Путь зависит от стороннего неофициального инструмента, а не от официального канала Apple.
