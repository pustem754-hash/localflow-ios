# Логика ядра — отдельный Swift-пакет, тесты идут на Linux в CI

## Контекст
На машине разработки нет Swift и нет Mac; сборка под iOS и macOS-раннер в GitHub Actions доступны только для финальной `.ipa`, а не для повседневной проверки логики.

## Решение
Вся логика, которую можно проверить без iPhone (отказ на выдуманном Whisper тексте, слова-паразиты, словарь замен, правила по длительности записи, параметры распознавания), собрана в отдельный пакет без зависимостей от iOS и использует только базовые возможности языка. Тестируется на раннере с Linux при каждом коммите.

## Почему
Рассмотрели и отвергли вариант держать всю логику внутри iOS-приложения одним куском: тогда для любой проверки, даже одной функции, нужен раннер с macOS, который для GitHub Actions заметно дороже минутами, чем раннер с Linux. Разделение позволяет проверять логику без iPhone и без Mac вообще.

## Последствия
Код, которому нужен UIKit или SwiftUI, не может лежать в этом пакете — приходится держать границу и иногда дублировать простые структуры данных между слоями. Любое изменение публичного интерфейса пакета ломает сборку приложения, пока не исправлено на обеих сторонах. Проверить код локально по-прежнему нельзя — только по зелёному прогону в CI.
