# Движок распознавания: whisper.cpp без Core ML, не WhisperKit

## Контекст
Нужен офлайн-движок распознавания русской речи на iPhone 11 (чип A13, 4 ГБ ОЗУ), работающий без интернета и без облака.

## Решение
Используем whisper.cpp, собранный с откатом с Core ML (вычисление на CPU/GPU); файлов `.mlmodelc` в сборке нет.

## Почему
- Рассмотрели и отвергли WhisperKit: на A12/A13 он официально отдаёт только модели tiny и base (по `config.json` на huggingface.co/argmaxinc/whisperkit-coreml), а у них на русском языке 31,1 % и 20,5 % ошибок по тесту FLEURS (arXiv 2212.04356) — слишком плохое качество для диктовки.
- Рассмотрели и отвергли ускорение через Core ML внутри whisper.cpp: по README whisper.cpp, Core ML-модель компилируется на устройстве при первом запуске; у похожего проекта на похожем железе (A12X, 4 ГБ) это закончилось тем, что систему убила приложение по памяти (issue в трекере GitHub) — риск недопустим на iPhone 11 с тем же объёмом памяти.
- whisper.cpp — открытый код (MIT), работает с любой моделью в формате ggml без заранее скомпилированных Core ML-артефактов.

## Последствия
Распознавание идёт на CPU/GPU медленнее, чем могло бы быть с рабочим Core ML-ускорением; насколько медленнее на реальном iPhone 11 — не измерено на этапе решения, и это первое, что проверяет экран «Замер». Если позже понадобится ускорение через Core ML, придётся заново решать проблему компиляции модели на устройстве с ограниченной памятью.
