# D02 — Параметры VAD по умолчанию faster-whisper, а не whisper.cpp

## Контекст
План предполагал, что десктопная версия LocalFlow задаёт для определения речи (VAD) только порог 0,3 и минимальную тишину 500 мс, а остальные поля можно взять по умолчанию движка распознавания на телефоне. По этому предположению в код сначала попали собственные умолчания whisper.cpp — поля речи 30 мс и минимальная длительность речи 250 мс.

## Решение
Используются умолчания библиотеки faster-whisper версии 1.2.1 (поля речи 400 мс, минимальная длительность речи 0 мс) — именно их десктопная версия LocalFlow применяет неявно, когда сама не задаёт эти два поля, а не умолчания, встроенные в whisper.cpp.

## Почему
Ревью сборки нашло, что спецификация упустила эту разницу: десктопная версия LocalFlow явно задаёт только порог и минимальную тишину, а оставшиеся поля VAD берёт по умолчанию из библиотеки распознавания — и это умолчание faster-whisper, а не whisper.cpp, у них разные значения. Отвергли вариант оставить умолчания whisper.cpp как более простой — он давал заметно другую нарезку речи, чем десктопная версия LocalFlow.

## Последствия
Поведение определения речи на телефоне ближе к привычному по десктопной версии LocalFlow, но отличается от поведения whisper.cpp «из коробки». При обновлении версии whisper.cpp эти два поля нужно будет сверять и держать руками, не доверяя новым умолчаниям библиотеки.
