# D01 — Загрузка модели обычной сессией, не фоновой

## Контекст
План предполагал только, что сеть нужна исключительно для однократной загрузки модели по явному нажатию пользователя; сама сборка на тот момент не включала точку входа приложения, через которую обычно настраивают фоновые сетевые задачи.

## Решение
Загрузка модели идёт обычной сетевой сессией, пока приложение открыто на экране, а не фоновой сессией, способной продолжать загрузку после ухода из приложения.

## Почему
Рассмотрели и отвергли фоновую сессию: для неё нужна отдельная точка входа приложения (`AppDelegate`), которой в сборке на тот момент не было и добавление которой выходило за рамки текущей задачи. Обычная сессия проще и укладывается в уже выбранную архитектуру SwiftUI-приложения без неё.

## Последствия
Если пользователь уходит из приложения или телефон блокируется во время загрузки модели, загрузка может оборваться; приложение показывает понятную ошибку и даёт повторить, а не докачивает файл в фоне. Загрузка модели требует держать телефон на экране с приложением до конца.
