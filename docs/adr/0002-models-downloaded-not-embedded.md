# Модели скачиваются при первом запуске, а не встраиваются в сборку

## Контекст
Для выбора модели нужно сравнить несколько вариантов по скорости, памяти и качеству текста на самом iPhone 11 — опубликованных замеров для этого устройства нет.

## Решение
Три модели (small, medium сжатая, large-v3-turbo сжатая) скачиваются пользователем из приложения по кнопке, с проверкой контрольной суммы файла после загрузки. Дополнительно можно занести файл без интернета — импортом из «Файлов» по точному размеру файла или через общий доступ iTunes.

## Почему
Рассмотрели и отвергли вариант встроить одну модель прямо в сборку: три модели вместе занимают около 1,6 ГБ, и до замера на реальном телефоне нет данных, какая из них подойдёт по скорости и качеству. Встраивание одной модели — осознанно отложено на отдельный шаг после того, как модель будет выбрана по результатам замера.

## Последствия
Первый запуск требует интернета хотя бы один раз, хотя дальше приложение работает полностью офлайн. Нужно поддерживать и показывать понятные ошибки для трёх путей появления модели на телефоне (скачивание, импорт из «Файлов», iTunes), а не один. Модели не входят в сборку и не версионируются в репозитории.
